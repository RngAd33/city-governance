# 交通信号配时优化前后对比报告

## 1. 实验概述

| 项目 | 说明 |
|------|------|
| 实验地点 | 南京市 |
| 优化路口 | INT-001, INT-002, INT-003 |
| 优化算法 | 遗传算法 |
| 仿真时长 | 60分钟 |
| 数据时段 | 早高峰 07:00-09:00 |

## 2. 优化方案

### 2.1 优化前配时

| 路口 | 相位 | 绿灯时间 | 周期 |
|------|------|----------|------|
| INT-001 | NS | 30s | 90s |
| INT-001 | EW | 25s | 90s |
| INT-002 | NS | 35s | 100s |
| INT-002 | EW | 30s | 100s |

### 2.2 优化后配时

| 路口 | 相位 | 绿灯时间 | 周期 |
|------|------|----------|------|
| INT-001 | NS | 38s | 84s |
| INT-001 | EW | 22s | 84s |
| INT-002 | NS | 42s | 96s |
| INT-002 | EW | 28s | 96s |

## 3. 对比结果

### 3.1 关键指标

| 指标 | 优化前 | 优化后 | 改善幅度 |
|------|--------|--------|----------|
| 平均等待时间 | 45.2s | 32.8s | ↓ 27.4% |
| 平均排队长度 | 120m | 78m | ↓ 35.0% |
| 路口通行量 | 1800veh/h | 2100veh/h | ↑ 16.7% |
| 平均车速 | 25km/h | 32km/h | ↑ 28.0% |
| 车辆启停次数 | 3.2次 | 2.1次 | ↓ 34.4% |
| 交通能耗 | 100kWh | 78kWh | ↓ 22.0% |
| 碳排放 | 25kg | 19.5kg | ↓ 22.0% |

### 3.2 分析

1. **等待时间降低27.4%**：优化后绿信比更匹配各相位流量需求
2. **排队长度减少35.0%**：周期缩短减少了车辆等待时间
3. **通行量提升16.7%**：更合理的相位时间分配提高了通行效率
4. **能耗降低22.0%**：启停次数减少降低了燃油消耗

## 4. 结论

遗传算法优化后的信号配时方案在各项指标上均有显著改善，验证了优化方法的有效性。
