# 交通信号配时优化实验

## 1. 实验目标

基于遗传算法对城市交通信号配时进行优化，验证优化前后在等待时间、排队长度、通行量、能耗等指标上的改善。

## 2. 输入数据

- 路段流量（vehicles/hour）
- 平均车速（km/h）
- 排队长度（m）
- 路口相位配置
- 历史高峰/平峰时段
- 天气、降雨、AQI等环境因素

## 3. 优化方法

### 3.1 遗传算法参数

| 参数 | 值 |
|------|-----|
| 种群规模 | 50 |
| 迭代次数 | 100 |
| 交叉概率 | 0.8 |
| 变异概率 | 0.1 |
| 选择策略 | 轮盘赌 |

### 3.2 编码方案

染色体 = [greenTime_phase1, greenTime_phase2, ..., greenTime_phaseN]

每个基因取值范围：[10, 120] 秒

### 3.3 适应度函数

```
fitness = Σ(flow_i × cycleLength × (1 - greenRatio_i)²) + penalty
```

其中：
- flow_i：相位i的流量
- cycleLength：信号周期
- greenRatio_i：相位i的绿信比
- penalty：违反约束的惩罚项

### 3.4 约束条件

- 最小绿灯时间 ≥ 10s
- 最大周期 ≤ 180s
- 行人过街安全时间 ≥ 15s
- 黄灯时间固定 3s

## 4. 目标指标

| 指标 | 说明 |
|------|------|
| 平均等待时间 | 车辆在路口的平均等待时间 |
| 平均排队长度 | 路口平均排队长度 |
| 路口通行量 | 单位时间通过路口的车辆数 |
| 平均车速 | 车辆通过路口的平均速度 |
| 车辆启停次数 | 车辆停车-启动次数 |
| 交通能耗 | 估算交通能耗 |
| 碳排放 | 估算碳排放量 |

## 5. 验证方式

### 5.1 仿真对比
- 使用优化前配时方案仿真
- 使用优化后配时方案仿真
- 对比各项指标

### 5.2 数据集验证
- 雄安多路口信号协同数据集
- 深圳街道级交通运行状态数据
- 中山大学城市级交通流数据

## 6. 预期结果

- 平均等待时间降低 15-30%
- 排队长度减少 20-40%
- 通行量提升 10-20%
- 车辆启停次数减少 25-35%
