# 测试文档

## 1. 测试策略

### 1.1 单元测试
- 各服务核心算法单元测试
- 事件模型序列化/反序列化测试
- 工具类测试

### 1.2 集成测试
- RabbitMQ事件总线通信测试
- 服务间数据流转测试
- 端到端业务流程测试

### 1.3 全链路测试
- 冒烟测试脚本验证所有服务健康检查
- 核心功能API测试

## 2. 测试用例

### 2.1 事件模型测试
- 事件创建与序列化
- 所有领域枚举覆盖
- 所有数据源枚举覆盖
- 路由键正确性验证

### 2.2 交通优化测试
- 遗传算法收敛性
- 约束条件满足性
- 优化前后对比

### 2.3 能耗分析测试
- 能耗强度计算
- 负荷预测准确性
- 节能潜力估算

### 2.4 环境监测测试
- AQI计算正确性
- 告警规则触发
- 趋势分析

### 2.5 水务风险测试
- 风险等级划分
- 洪涝模拟
- 排水能力分析

### 2.6 政务AI测试
- 告警解释生成
- 报告生成
- 预案检索

## 3. 运行测试

```bash
# 单元测试
mvn test

# 全链路冒烟测试
chmod +x scripts/smoke-test.sh
./scripts/smoke-test.sh
```
